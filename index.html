  • Smart UI Scaler

    Smart UI Scaler makes one Unity UI layout fit every screen. Design your UI once at a reference resolution and it fits any screen size, aspect ratio, safe area or camera viewport, growing toward the edges exactly as far as you allow. Works per Rect Transform, so HUD, menus, popups and split-screen viewports each scale on their own terms.
